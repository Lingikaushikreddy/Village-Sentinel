# Village strategy expansion

User selected: build, gather resources, defend and trade. Continue the existing public game and PR, using original art and the existing native JS stack. The existing isolated checkout is suitable. No cloud resources or paid services.

Design: a large isometric clearing with timber buildings, crops, stone walls and visible workers. Dark forest HUD, parchment controls, gold resource counters, teal mission highlights. The map is the primary screen; the six teaching characters and existing mission evidence remain accessible. This is an original single-player browser simulation inspired by village strategy games, with no copied assets or multiplayer claim.

Gameplay: persistent local village; place farms, timber camps, watchtowers and markets on open grid cells; upgrade to level 3; production and food consumption on deterministic ticks; trading, repairs and increasingly strong periodic raids; win by reaching eight buildings, defending three raids and completing an AI mission. Defeat at zero village integrity. Pause and speed controls; no offline time advances. No paid model calls from the builder.

Truth boundary: player building state is a browser simulation. Existing missions use the same recorded/live provider wiring and their own permitted world observations. Mission completion grants a clearly labeled one-time construction reward per scenario. Never imply recorded Decider results were computed for the user's custom buildings.
