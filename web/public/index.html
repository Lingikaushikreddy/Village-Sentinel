Your 60-second village tour

A claim is not a command.

A villager hears a message. The AI must choose what to do with it, and the village has to live with that choice.

  1. Hear the claim.Start with The notice. The message asks for eight coins, but a normal grain trade costs two.
  2. Watch Pip choose.Decider 2B selects an available tool and returns probabilities. It does not write an explanation.
  3. Check the source.If the agent investigates, the villager moves to the evidence. The next decision gets the new observation.
  4. See the consequence.Gus applies the action. Did the resident pay, decline, or keep investigating? Then try The fair trade.
